# 万用表测量手册 —— 5 个测量点定位舵机问题

> 用途：买了万用表回来，照这个顺序量。
> 目标：把「5V 没到 / 共地断了 / 信号线断 / 供电不足 / 舵机烧了」五个嫌疑，
> 用测量结果一次分开。
> 前置：PWM 波形已用固件自测证实正常（`pw_avg=1499us / per_avg=20000us`），不用再怀疑代码。

---

## 测量点总览（先看这张表，知道要量哪 5 个地方）

| # | 量什么 | 档位 | 表笔怎么放 | 期望值 | 判据 |
| :-: | :--- | :--- | :--- | :--- | :--- |
| **1** | 舵机电源电压 | 直流电压 DCV 20V | 黑→舵机棕线，红→舵机红线 | **4.8 ~ 5.2 V** | 0V = 没电；<4.5V = 供电偏弱 |
| **2** | 共地是否连通 | 通断档（蜂鸣） | 黑→电源 OUT-，红→ESP32 GND 针 | **响（≈0Ω）** | 不响 = 共地断了 ★头号嫌疑 |
| **3** | 信号线是否连通 | 通断档（蜂鸣） | 黑→舵机橙线端子，红→ESP32 GPIO14 | **响（≈0Ω）** | 不响 = 橙线断/插错针 |
| **4** | PWM 是否到了舵机端 | 直流电压 DCV 20V | 黑→ESP32 GND，红→舵机橙线端子 | **≈0.25 V** | 0V = 信号没到；0.25V = 到了 |
| **5** | 带载时电压掉多少 | 直流电压 DCV 20V | 黑→舵机棕线，红→舵机红线 | **动作时不低于 4.5V** | 掉到 3.x V = 供电带不动 |

**做 1、4、5 时通电；做 2、3 时必须断电。**

## 测量 1：5V 到底有没有到舵机

**这是最重要的一次测量。** 昨晚所有推论最后都指向这里。

### 怎么做

1. 通电（ESP32 插上 USB，外部 5V 电源打开）
2. **不用发任何命令**，舵机静止
3. 万用表打到 **DCV 20V 档**（有些表是 `V⎓` 或 `DC V`）
4. **黑表笔**戳舵机那根**棕/黑线**的金属部分
5. **红表笔**戳舵机那根**红线**的金属部分

> 技巧：杜邦线头的塑料壳挡着，可以把表笔尖从塑料壳侧面插进去，
> 或者把探针压在排针与线的接缝金属上。接触不稳会有跳动，多试几下取稳定值。

### 读数怎么判

| 读数 | 结论 | 下一步 |
| :--- | :--- | :--- |
| **4.8 ~ 5.2 V** | ✅ 5V 正常到了 | 去测 2（共地） |
| **0 V** | ❌ 供电根本没到 | 往上查电源：电源输出端有没有 5V？线有没有接错？ |
| **3.x ~ 4.5 V** | ⚠️ 电压偏低 | 电源带不动 / DC 模块调错 / 线太细太长 |
| **8~12 V** | ⚠️ 接成 12V 输入侧了 | **立刻断电！** 舵机已可能损坏 |

### 如果读到 0V，继续往上追

把表笔从舵机端往外挪，逐段测：

```
外部电源 OUT+ ──[测A]── 杜邦线 ──[测B]── 舵机红线
```

- **测 A**（直接量电源 OUT+ 对 OUT-）有没有 5V？
  - 没有 → 电源本身没输出，或没通电，或 DC 模块输入侧没接 12V
  - 有 → 问题在中间那段线（测 B）

这样能精确定位「哪一段断了」，而不是笼统地「不工作」。

## 测量 2：共地到底通不通（★ 头号嫌疑）

**这是昨晚最怀疑的一条。** 症状和「没电」完全一样，但原因完全不同。

### 怎么做

1. **全部断电**（拔掉 USB、关掉外部电源）
2. 万用表打到**通断档**（蜂鸣档，符号通常是 `🔊` 或 `◁|` 或二极管档）
3. **黑表笔**戳外部电源的 **OUT-**
4. **红表笔**戳 **ESP32 板子上的 GND 针**

### 读数怎么判

| 结果 | 结论 |
| :--- | :--- |
| **蜂鸣响 / 读数 ≈0 Ω** | ✅ 共地正常 |
| **不响，读数是 1 或 OL** | ❌ **共地断了 —— 这就是根因** |

### 如果断了怎么修

**加一根线：** `外部电源 OUT- ──── ESP32 的 GND 针`

这根线没有任何替代品。PWM 是「相对 GND 的电压信号」，
两边地不连通，舵机看到的就不是 3.3V 方波，而是一团没有参考的乱电平。

> **为什么这条最像你的症状**：
> 你说「完全没声音、摇臂很松」。
> 如果舵机通电但信号是乱码，SG90 不会驱动电机 → 没有保持力矩 → 摇臂很松。
> 而舵机自己那一路电源（OUT+ → OUT-）是通的，所以它「有电但没信号」，
> 表现就是完全静止、无声音、无自锁。

## 测量 3：橙线有没有真的接到 GPIO14

### 怎么做

1. **全部断电**
2. 通断档
3. **黑表笔**戳**舵机端的橙线**金属部分（靠近舵机那一头，确保测的是线本身）
4. **红表笔**戳 **ESP32 板子上丝印 GPIO14 的那根针**

### 读数怎么判

| 结果 | 结论 |
| :--- | :--- |
| **响** | ✅ 橙线确实在 GPIO14 上 |
| **不响** | ❌ 线断了，或插到了别的针（比如隔壁的 5Vin / GND） |

### 如果不响

三孔塑料壳**整体偏移一格**是很常见的错误。壳体套在这三个针上时，
橙线可能落在 `5Vin` 或 `GND` 上，而不是 `GPIO14`。

可以逐个试：红表笔依次戳 GPIO14 / GPIO13 / GPIO12 / 5Vin / GND，
看哪个响。

> 找到真实落点后，可以用固件的 `G <pin>` 命令运行时改引脚，不用重烧：
> `G 13` 就把 PAN 通道改到 GPIO13。

## 测量 4：PWM 信号有没有到舵机端

这一步能证明「信号确实传到了舵机那一头」，不只是出到 ESP32 的引脚上。

### 原理（为什么直流档能测 PWM）

普通万用表量不了 50Hz 方波的波形，但**直流电压档读的是平均值**。
PWM 的平均电压 = 占空比 × 峰值电压：

```
中位 1500us / 20000us = 7.5% 占空比
7.5% × 3.3V = 0.2475V  ≈ 0.25V
```

所以只要读到稳定的 ≈0.25V，就说明 PWM 真的到了这里。

### 怎么做

1. 通电，ESP32 正常通信
2. 通过 `servo_live.py` 或直接发命令让舵机**停在中位**（`P 0 0`）
3. 万用表 **DCV 20V 档**
4. **黑表笔**戳 **ESP32 的 GND 针**
5. **红表笔**戳 **舵机端的橙线**金属部分

### 读数怎么判

| 指令 | 脉宽 | 占空比 | 期望读数 |
| :--- | :--- | :--- | :--- |
| `P 0 0` | 1500us | 7.5% | **≈0.25 V** |
| `P 45 0` | 2000us | 10% | **≈0.33 V** |
| `P -45 0` | 1000us | 5% | **≈0.17 V** |

| 实测 | 结论 |
| :--- | :--- |
| **0.25V 左右，改角度会变** | ✅ 信号完整到达舵机端，问题只可能在供电/共地/舵机本身 |
| **恒定 0V** | ❌ 信号没到这根线（结合测量 3 判断是线断还是插错针） |
| **恒定 3.3V** | ❌ 接到 3V3 电源针上了，不是信号脚 |

> 这个测试很妙：**同一个探针位置，改角度时读数从 0.17 → 0.25 → 0.33 跟着变**，
> 就同时证明了「有 PWM」和「PWM 会响应指令」两件事。

## 测量 5：供电够不够（带载压降）

这个测「电源是不是带不动」。

### 怎么做

1. 通电，表笔保持：**黑→舵机棕线，红→舵机红线**
2. 先读静止时的电压（空载，舵机不动作）→ 记下来
3. 发命令让舵机**持续摆动**（`servo_live.py`）
4. 盯着读数看，记下摆动时的**最低值**

### 读数怎么判

| 空载 | 带载 | 结论 |
| :--- | :--- | :--- |
| 5.0 V | **≥4.5 V** | ✅ 供电充足 |
| 5.0 V | **3.x V** | ❌ 供电带不动（线太细 / 电源功率不够 / 舵机堵转） |
| 5.0 V | **掉到 2V 以下** | ❌ 严重不足，或舵机内部短路 |

> 如果带载掉压很厉害，先拔掉一颗舵机（如果接了两颗）再测。
> 两颗 SG90 峰值接近 2.8A，很多小模块和 USB 口根本带不动。

## 五组测量的组合判读表

测完之后，把结果套进这张表，基本就能定位：

| 测1 电压 | 测2 共地 | 测3 信号线 | 测4 PWM | 结论 | 怎么修 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| ✅ 5V | ✅ 通 | ✅ 通 | ✅ 0.25V | **电气全对，舵机坏了** | 换舵机（MG90S） |
| ✅ 5V | ❌ 断 | ✅ 通 | ✅ 0.25V | **共地断了** ← 头号 | 加一根 GND 线 |
| ✅ 5V | ✅ 通 | ❌ 断 | ❌ 0V | **橙线断/插错针** | 换线，或 `G <pin>` 改引脚 |
| ❌ 0V | 任意 | 任意 | 任意 | **没电到舵机** | 查电源输出、逐段量线 |
| ✅ 5V | ✅ 通 | ✅ 通 | ❌ 0V | 线断了（但通断档没测出来） | 换橙线 |
| 5V→3.x V（带载） | ✅ 通 | ✅ 通 | ✅ | **供电带不动** | 换大电流电源 / 只接一颗 |
| ✅ 5V | ✅ 通 | ✅ 通 | ✅ 但摇臂松 | 舵机内部损坏 | 换舵机 |

## 安全注意事项

1. **测 2、3（通断）必须断电做。** 带电用通断档可能损坏万用表，也可能读到假值。
2. **不要用电流档去量电压。** 电流档内阻几乎为 0，接到 5V 上会**直接短路**，
   烧表或者烧电源。（这是新手最常见的毁表方式）
3. **表笔不要同时碰到相邻两个针。** 排针间距只有 2.54mm，很容易短路。
   建议只用一支笔移动，另一支固定在一个点上。
4. **量到 8~12V 立刻断电。** 说明接错到 12V 输入侧了，舵机可能已经损坏。
5. 手不要同时接触两个探针的金属部分（会影响读数，也危险）。

## 附：万用表基础操作（没用过的话看这里）

**插表笔**
- 黑表笔 → `COM` 孔
- 红表笔 → `VΩmA` 孔（**不要插 10A 孔**，那是测电流用的，容易烧表）

**选档位**
- 测电压：转盘打到 `V⎓` 或 `DCV` 的 **20** 档
- 测通断：转盘打到 `🔊` 或 `◁|` 或二极管符号（通常和电阻档在一起）

**读数**
- 显示 `1` 或 `OL` = 超出量程 / 断路
- 显示 `0.00` = 短路 / 无电压
- 通断档响 = 通；不响 = 不通

**表笔握法**
- 像握笔一样握，拇指和食指捏在绝缘部分
- 尖端垂直压在被测物金属上，别歪（歪了接触面积小，读数会跳）

**先自检**
拿到表先做一次自检，确认表本身是好的：
1. 通断档，两支表笔尖互相碰 → **应该响**（证明通断档正常）
2. DCV 20V 档，量一节新 5 号电池 → **应该读 1.5~1.6V**（证明电压档正常）

> 这一步很重要：**没有对照的测量结果不能用于归因。**
> 如果通断档本来就不响，你量出来「共地不响」就毫无意义。
